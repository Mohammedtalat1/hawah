# Hawah Mobile App — تطبيق حوة للهواتف الذكية

تطبيق إسلامي شامل مبني باستخدام **Flutter** و **Dart** يتبع معمارية **Offline-First + Online Content** مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).

---

## 1. المتطلبات للتشغيل على جهاز التطوير (Development Setup)

- **Flutter SDK** الإصدار 3.16 أو أحدث
- **Android Studio** مع Android SDK و Command-line Tools
- **Node.js** (فقط لتشغيل أداة تجهيز البيانات `setup_data.js`)

---

## 2. خطوات البناء والتثبيت (Build & Install Steps)

### الخطوة 1: تنزيل ملفات البيانات والخطوط الموثقة
قبل بناء التطبيق لأول مرة، قم بتشغيل أداة تجهيز البيانات لتنزيل نصوص القرآن الموثقة من Tanzil.net والأحاديث النبوية والخطوط العربية إلى مجلد `assets`:

```bash
# من المجلد الرئيسي للمشروع
node tools/setup_data.js
```

### الخطوة 2: تثبيت حزم Flutter
```bash
cd mobile
flutter pub get
```

### الخطوة 3: إنشاء ملفات قاعدة البيانات و Riverpod (اختياري / في حال الرغبة بإعادة التوليد)
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### الخطوة 4: تشغيل التطبيق في وضع التطوير
لتحديد عنوان الخادم الخلفي (API):
```bash
# للمحاكي (Android Emulator)
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000/api

# للهاتف الحقيقي عبر الشبكة المحلية (WiFi)
flutter run --dart-define=API_BASE_URL=http://192.168.1.X:3000/api
```

### الخطوة 5: بناء ملف APK للتثبيت على هاتفك المحمول
```bash
flutter build apk --release --dart-define=API_BASE_URL=https://your-api-domain.com/api
```

ستجد ملف التطبيق الناتج جاهزاً في:
`mobile/build/app/outputs/flutter-apk/app-release.apk`

قم بنقله إلى هاتفك وتثبيته مباشرة.

## 3. مميزات التطبيق (Features)

1. **القرآن الكريم كاملاً بدون إنترنت**:
   - 114 سورة كاملة مع أسماء السور وأرقام الآيات.
   - خط مصحف عثماني موثق (Amiri).
   - تحكم كامل بحجم الخط.
   - حفظ تلقائي لآخر موضع قراءة مع بطاقة متابعة القراءة في الرئيسية.
   - علامات مرجعية ونسخ ومشاركة الآيات.
   - بحث فوري وسريع في آيات القرآن الكريم.

2. **الأحاديث النبوية الشريفة بدون إنترنت**:
   - صحيح البخاري وصحيح مسلم.
   - تصفح وتصفية وحفظ الأحاديث.
   - بحث سريع في متون الأحاديث.

3. **المسبحة الإلكترونية**:
   - عداد دائري تفاعلي مع اهتزازات حسية (Haptic feedback).
   - أذكار مسبقة قابلة للتخصيص.
   - خيارات متعددة للأهداف (33، 34، 100...).
   - سجل محفوظات التسبيح محلياً في SQLite.

4. **اتجاه القبلة الشريفة**:
   - بوصلة واقعية معتمدة على مستشعر المغناطيسية وموقع GPS.
   - حساب دقيق لزاوية القبلة الدائرية العظمى باتجاه الكعبة المشرفة.
   - مؤشر استقامة واهتزاز عند التوجه الصحيح.

5. **الأدعية والأذكار**:
   - أذكار الصباح والمساء وأدعية القرآن والسفر.
   - تصفية وتصنيف مع بحث سريع.
   - حفظ ومشاركة.

6. **البودكاست والفيديوهات ومكتبة الكتب (PDF)**:
   - الاستماع والمشاهدة من مصادر خارجية موثوقة.
   - تحميل الكتب وقراءتها دون اتصال بالإنترنت عبر قارئ PDF المدمج.

7. **لوحة تحكم المدير (Admin Dashboard)**:
   - تسجيل دخول آمن للمدير.
   - إضافة وتعديل وحذف ونشر المحتوى والتصنيفات مباشرة من التطبيق.
